## 1. О проекте

**MatrixLab** — это образовательный веб-сервис, который помогает студентам,
преподавателям и инженерам решать задачи линейной алгебры **пошагово**, с
объяснением каждого действия.

В отличие от обычных калькуляторов матриц, MatrixLab показывает **не только
ответ**, но и **как он был получен**: разложение на элементарные операции,
промежуточные формулы, проверки корректности.

Проект написан на **Python 3.14** с использованием **Django 5.1** и
**SymPy 1.13** для символьных вычислений. Интерфейс — на русском языке,
с поддержкой английского.

### Ключевые принципы

- 🎯 **Точность** — символьные вычисления вместо плавающей точки
- 📚 **Обучение** — каждое решение сопровождается пошаговым объяснением
- ⚡ **Скорость** — кэширование, асинхронные задачи, оптимизация MathJax
- 🎨 **Удобство** — современный UI, тёмная тема, адаптивность
- ♿ **Доступность** — ARIA, клавиатурная навигация, `prefers-reduced-motion`
- 🔒 **Безопасность** — CSRF, XSS-защита, rate limiting, bandit

## 2. Возможности

### 2.1. Операции с матрицами

| Операция | Описание | Пошагово |
|---|---|---|
| **Сложение** | `A + B` | ✅ |
| **Вычитание** | `A - B` | ✅ |
| **Умножение** | `A × B` | ✅ |
| **Умножение на скаляр** | `k × A` | ✅ |
| **Транспонирование** | `Aᵀ` | ✅ |
| **Возведение в степень** | `Aⁿ` | ✅ |
| **Определитель** | `det(A)` | ✅ |
| **Обратная матрица** | `A⁻¹` | ✅ |
| **Ранг** | `rank(A)` | ✅ |
| **След** | `tr(A)` | ✅ |
| **Произведение Кронекера** | `A ⊗ B` | ✅ |

### 2.2. Свойства матриц

- Симметричность, кососимметричность
- Ортогональность, унитарность
- Положительная определённость
- Диагонализуемость
- Нильпотентность
- Идемпотентность
- Норма (Фробениуса, спектральная, 1, ∞)

### 2.3. СЛАУ (системы линейных алгебраических уравнений)

- **Метод Гаусса** — с выбором главного элемента
- **Метод Гаусса-Жордана** — приведение к единичной
- **Матричный метод** — через обратную матрицу
- **Метод Крамера** — через определители
- **LU-разложение** — с частичным выбором
- **Проверка совместности** — теорема Кронекера-Капелли
- **Фундаментальная система решений** — для неопределённых систем

### 2.4. Разложения

| Разложение | Описание | Пошагово |
|---|---|---|
| **LU** | Нижняя × верхняя треугольные | ✅ |
| **LUP** | LU с перестановкой | ✅ |
| **QR** | Ортогональная × верхняя | ✅ |
| **Холецкого** | Для положительно определённых | ✅ |
| **SVD** | Сингулярное разложение | ✅ |
| **Спектральное** | Для симметричных | ✅ |

### 2.5. Собственные значения и векторы

- Характеристический многочлен
- Собственные значения (точные и численные)
- Собственные векторы
- Алгебраическая и геометрическая кратность
- Спектр матрицы
- Инварианты (след, определитель)

### 2.6. Интерфейс

- 📱 **Адаптивный дизайн** — от 360px до 4K
- 🌗 **Тёмная / светлая тема** — с автоопределением
- 🎬 **Анимации** — аккуратные, с `prefers-reduced-motion`
- 📊 **MathJax** — красивые формулы
- 💾 **История** — сохранение вычислений
- 📤 **Экспорт** — LaTeX, PDF, PNG
- 🖨️ **Печать** — оптимизированные стили

## 5. Быстрый старт

### 5.1. Требования

- **Python 3.14+**
- **pip** или **uv**
- **Git**

### 5.2. Установка за 60 секунд

```bash
# Клонировать репозиторий
git clone https://example.com/matrixlab/repo.git
cd matrixlab

# Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# Установить зависимости
pip install -e ".[dev]"

# Применить миграции
python manage.py migrate

# Создать суперпользователя
python manage.py createsuperuser

# Запустить сервер
python manage.py runserver
