Что такое спектр матрицы

Собственные значения и векторы — ключ к пониманию линейного оператора.

{% icon "lambda" size=22 %}

Собственные значения

Число λ — собственное значение, если уравнение Av = λv имеет ненулевое решение v.

$\det(A - \lambda I) = 0$

Многочлен det(A − λI) называется характеристическим. Его корни — собственные значения матрицы A.

{% icon "vector" size=22 %}

Собственные векторы

Для каждого λ решаем (A − λI)v = 0. Фундаментальная система решений даёт базис собственного подпространства.

  • Геометрическая кратность — размерность подпространства.
  • Алгебраическая кратность — кратность корня λ.
  • Геометрическая кратность не превышает алгебраическую.
{% icon "check-badge" size=22 %}

Диагонализируемость

Матрица диагонализируема, если существует базис из собственных векторов. Это равносильно тому, что для каждого λ геометрическая кратность равна алгебраической.

$A = P \Lambda P^{-1}$

Диагональная матрица Λ содержит собственные значения, столбцы P — собственные векторы.

{% icon "sigma" size=22 %}

Инварианты

След и определитель выражаются через собственные значения:

$\operatorname{tr}(A) = \sum \lambda_i$
$\det(A) = \prod \lambda_i$

Эти соотношения удобны для проверки правильности вычислений.
