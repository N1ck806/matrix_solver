Что такое собственные значения?

Понимание спектра — ключ к анализу линейных преобразований.

{% icon "lambda" size=22 %}

Определение

Число $\lambda$ называется собственным значением матрицы $A$, если существует ненулевой вектор $v$, такой что

$$A v = \lambda v$$

Вектор $v$ при этом называется собственным вектором, отвечающим $\lambda$.

{% icon "determinant" size=22 %}

Как находятся

Из характеристического уравнения

$$\det(A - \lambda I) = 0$$

Это многочлен степени $n$ относительно $\lambda$, его корни — собственные значения матрицы $n \times n$.

{% icon "hash" size=22 %}

Кратности

Алгебраическая кратность — кратность $\lambda$ как корня характеристического многочлена.

Геометрическая кратность — размерность собственного подпространства $\ker(A - \lambda I)$.

Всегда: геометрическая $\le$ алгебраическая.

{% icon "sparkles" size=22 %}

Смысл и применения

Собственные значения показывают, во сколько раз преобразование растягивает векторы вдоль собственных направлений.

  • Устойчивость динамических систем
  • Метод главных компонент (PCA)
  • Квантовая механика, теория колебаний
  • Марковские цепи, PageRank
