    Когда применять какое разложение

    Краткий гид по выбору метода для конкретной задачи.

    {% icon "lu" size=22 %}

    LU-разложение

    $A = L \cdot U$

    Когда нужно решать одну и ту же систему с разными правыми частями или вычислять определитель как произведение диагоналей $U$.

    Применимо к любой матрице (с пивотингом)
    {% icon "qr" size=22 %}

    QR-разложение

    $A = Q \cdot R$

    Для метода наименьших квадратов, QR-алгоритма поиска собственных значений и численно устойчивого решения систем.

    Требуется $m \ge n$
    {% icon "diagonal" size=22 %}

    Холецкого

    $A = L \cdot L^{T}$

    Ускоренное разложение для симметричных положительно определённых матриц. Вдвое быстрее LU.

    Симметричная положительно определённая
    {% icon "diagonalize" size=22 %}

    Диагонализация

    $A = P \cdot D \cdot P^{-1}$

    Быстрое вычисление $A^n$, решение систем ОДУ $x' = Ax$, понимание структуры преобразования.

    Диагонализируемая матрица
    {% icon "symmetric" size=22 %}

    Спектральное

    $A = Q \cdot D \cdot Q^{T}$

    Ортогональная диагонализация симметричной матрицы. Широко используется в PCA, квантовой механике, теории колебаний.

    Только симметричная
