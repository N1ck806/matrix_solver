Теория

Три определения, с которых всё начинается

Линейное отображение, собственный вектор, разложение — три понятия, на которых стоит весь курс. Каждое из них описывает одно и то же преобразование с разных сторон.

Линейное отображение
A · v = w

Вектор входит, вектор выходит

Собственный вектор
A · v = λ · v

Направление не меняется, длина — да

Разложение
A = L · U

Сложное — на простые множители

Вопросы

Часто спрашивают

Короткие ответы на типичные вопросы о сервисе.

{% icon "arrow-right" size=14 %} Вычисления точные или приближённые?

Точные. Дроби остаются дробями, корни — корнями, комплексные числа — комплексными. Никакого промежуточного перехода в float, как в обычных калькуляторах.

{% icon "arrow-right" size=14 %} Что можно вводить в матрицу?

Целые и отрицательные числа, дроби (1/2), десятичные (-4.5), корни (sqrt(2)), константы (2*pi), комплексные числа (2+3i), символьные выражения с параметрами.

{% icon "arrow-right" size=14 %} Какого размера матрицы поддерживаются?

До 10×10 в стандартном режиме. Для символьных вычислений — до 5×5. Для СЛАУ расширенная матрица до 10×11.

{% icon "arrow-right" size=14 %} Можно ли экспортировать решение?

Да. Результат можно скопировать в LaTeX, JSON или текстовом виде и вставить в отчёт, статью или учебную работу.

{% icon "arrow-right" size=14 %} Есть ли API?

Да. Все операции доступны через JSON API по адресу /api/<operation>/. Подходит для интеграции в учебные проекты, ботов и внешние приложения.

{% icon "arrow-right" size=14 %} Где хранятся мои данные?

История вычислений и сохранённые матрицы хранятся в вашем браузере и никуда не передаются. Историю можно очистить в один клик или методом очистки кэша в браузере.
