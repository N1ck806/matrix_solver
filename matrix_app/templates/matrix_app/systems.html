Теорема Кронекера-Капелли

Критерий совместности системы линейных уравнений.

Система $Ax = b$ совместна тогда и только тогда, когда

$$\operatorname{rank}(A) = \operatorname{rank}([A \mid b])$$

  • {% icon "check-circle" size=20 %}
    Единственное решение $\operatorname{rank}(A) = \operatorname{rank}([A|b]) = n$
  • {% icon "info" size=20 %}
    Бесконечно много решений $\operatorname{rank}(A) = \operatorname{rank}([A|b]) < n$
  • {% icon "alert-circle" size=20 %}
    Решений нет $\operatorname{rank}(A) \neq \operatorname{rank}([A|b])$
