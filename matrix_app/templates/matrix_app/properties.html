Форма матрицы

Определяется соотношением числа строк и столбцов.

Форма

Квадратная

Матрица, у которой число строк равно числу столбцов.

$$m = n$$
Пример: $$\begin{pmatrix}1&2\\3&4\end{pmatrix}$$
Проверка: число строк = число столбцов
Зачем: Только для квадратных определены определитель и обратная матрица.
Форма

Прямоугольная

Матрица, у которой число строк не равно числу столбцов.

$$m \neq n$$
Пример: $$\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$$ (2×3)
Важно: Не имеет определителя и обратной матрицы.
Форма

Строка / Столбец

Матрица размера $1 \times n$ (строка) или $m \times 1$ (столбец). Также называется вектором.

$$m = 1 \;\text{или}\; n = 1$$
Пример: $$(1,\ 2,\ 3)$$ или $$\begin{pmatrix}1\\2\\3\end{pmatrix}$$

Структура матрицы

Расположение нулевых и ненулевых элементов.

Структура

Диагональная

Квадратная матрица, у которой все внедиагональные элементы равны нулю.

$$a_{ij} = 0 \quad \text{при} \quad i \neq j$$
Пример: $$\begin{pmatrix}1&0&0\\0&5&0\\0&0&3\end{pmatrix}$$
Структура

Единичная

Диагональная матрица, у которой все элементы на главной диагонали равны 1.

$$a_{ij} = \delta_{ij}$$
Пример: $$I_3 = \begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}$$
Зачем: Нейтральный элемент умножения: \(AI = IA = A\).
Структура

Треугольная

Квадратная матрица, у которой все элементы выше (нижняя треугольная) или ниже (верхняя треугольная) главной диагонали равны нулю.

$$a_{ij} = 0 \quad \text{при} \quad i < j \quad \text{(нижняя)}$$
Пример: $$\begin{pmatrix}1&0&0\\2&5&0\\3&4&3\end{pmatrix}$$
Структура

Ленточная

Матрица, у которой ненулевые элементы расположены только на главной диагонали и нескольких прилегающих диагоналях.

$$a_{ij} = 0 \quad \text{при} \quad |i - j| > k$$
Пример: Трёхдиагональная матрица (k = 1).
Структура

Разреженная

Матрица, в которой большинство элементов равно нулю.

$$\text{nnz}(A) \ll mn$$
Зачем: Экономия памяти и ускорение вычислений.

Симметрия

Свойства, связанные с равенством элементов относительно диагонали.

Симметрия

Симметричная

Квадратная матрица, равная своей транспонированной.

$$A = A^T \quad \Leftrightarrow \quad a_{ij} = a_{ji}$$
Пример: $$\begin{pmatrix}1&2\\2&5\end{pmatrix}$$
Симметрия

Кососимметричная

Квадратная матрица, равная своей транспонированной с обратным знаком.

$$A = -A^T \quad \Leftrightarrow \quad a_{ij} = -a_{ji}$$
Пример: $$\begin{pmatrix}0&-2\\2&0\end{pmatrix}$$
Следствие: Диагональные элементы равны нулю.
Симметрия

Ортогональная

Квадратная матрица, произведение которой на транспонированную равно единичной.

$$A^T A = A A^T = I$$
Пример: Матрица поворота на угол \(\theta\).
Зачем: Сохраняет длины векторов и углы между ними.
Симметрия

Эрмитова

Комплексная квадратная матрица, равная своей сопряжённо-транспонированной.

$$A = A^* = \overline{A}^T$$
Следствие: Диагональные элементы вещественны.

Определённость

Знак квадратичной формы, порождаемой симметричной матрицей.

Определённость

Положительно определённая

Симметричная матрица, для которой квадратичная форма положительна при любом ненулевом векторе.

$$x^T A x > 0 \quad \forall x \neq 0$$
Проверка: Все собственные значения \(> 0\).
Определённость

Отрицательно определённая

Симметричная матрица, для которой квадратичная форма отрицательна при любом ненулевом векторе.

$$x^T A x < 0 \quad \forall x \neq 0$$
Проверка: Все собственные значения \(< 0\).
Определённость

Неопределённая

Симметричная матрица, квадратичная форма которой принимает как положительные, так и отрицательные значения.

$$\exists x,\ y: \ x^T A x > 0,\ y^T A y < 0$$
Проверка: Собственные значения разных знаков.

Особые виды матриц

Матрицы с дополнительными алгебраическими свойствами.

Особый вид

Идемпотентная

Матрица, которая при возведении в квадрат равна самой себе.

$$A^2 = A$$
Пример: Матрица проекции.
Особый вид

Нильпотентная

Матрица, некоторая степень которой равна нулевой матрице.

$$A^k = 0 \quad \text{для некоторого } k > 0$$
Пример: $$\begin{pmatrix}0&1\\0&0\end{pmatrix}$$
Особый вид

Инволютивная

Матрица, которая при возведении в квадрат равна единичной.

$$A^2 = I$$
Пример: Матрица отражения.
Особый вид

Унитарная

Комплексная квадратная матрица, произведение которой на сопряжённо-транспонированную равно единичной.

$$U^* U = U U^* = I$$
Зачем: Сохраняет скалярное произведение в комплексном пространстве.

Числовые характеристики

Скалярные величины, связанные с матрицей.

Числовая

Определитель

Скалярная величина, характеризующая линейное преобразование.

$$\det(A) = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \prod_{i=1}^n a_{i,\sigma(i)}$$
Свойство: \(\det(A) = 0 \Leftrightarrow\) матрица вырождена.
Числовая

След

Сумма элементов главной диагонали квадратной матрицы.

$$\operatorname{tr}(A) = \sum_{i=1}^n a_{ii}$$
Свойство: \(\operatorname{tr}(A) = \sum \lambda_i\) (сумма собственных значений).
Числовая

Ранг

Максимальное число линейно независимых строк (или столбцов).

$$\operatorname{rank}(A) = \dim(\operatorname{Im} A)$$
Свойство: \(\operatorname{rank}(A) \le \min(m, n)\).
Числовая

Спектр (собственные значения)

Множество чисел \(\lambda\), при которых уравнение \(Ax = \lambda x\) имеет ненулевое решение.

$$\det(A - \lambda I) = 0$$
Зачем: Определяют устойчивость, диагонализуемость и динамику систем.

Вырожденность

Свойства, связанные с обратимостью и линейной зависимостью.

Вырожденность

Невырожденная (обратимая)

Квадратная матрица, определитель которой отличен от нуля.

$$\det(A) \neq 0$$
Свойство: Существует обратная матрица \(A^{-1}\).
Вырожденность

Вырожденная (необратимая)

Квадратная матрица, определитель которой равен нулю.

$$\det(A) = 0$$
Следствие: Строки (столбцы) линейно зависимы; обратной матрицы не существует.
Вырожденность

Обратная матрица

Матрица \(A^{-1}\), для которой \(A A^{-1} = A^{-1} A = I\).

$$A^{-1} = \frac{1}{\det(A)} \operatorname{adj}(A)$$
Условие: \(\det(A) \neq 0\).
