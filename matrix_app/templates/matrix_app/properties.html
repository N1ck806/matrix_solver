Форма матрицы

Определяется соотношением числа строк и столбцов.

Форма

Квадратная

Матрица, у которой число строк равно числу столбцов.

$$m = n$$
Пример: $$\begin{pmatrix}1&2\\3&4\end{pmatrix}$$
Проверка: число строк = число столбцов
Зачем: Только для квадратных определены определитель и обратная матрица.
Форма

Прямоугольная

Матрица, у которой число строк не равно числу столбцов.

$$m \neq n$$
Пример: $$\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$$ (2×3)
Важно: Не имеет определителя и обратной матрицы.
Форма

Строка / Столбец

Матрица размера $1 \times n$ (строка) или $m \times 1$ (столбец). Также называется вектором.

$$m = 1 \;\text{или}\; n = 1$$
Пример: $$(1,\ 2,\ 3)$$ или $$\begin{pmatrix}1\\2\\3\end{pmatrix}$$
Зачем: Векторы — частный случай матриц, используются в СЛАУ и геометрии.

Структура элементов

Расположение нулей и ненулевых элементов.

Структура

Нулевая

Все элементы равны нулю.

$$a_{ij} = 0 \;\forall i,j$$
Пример: $$\begin{pmatrix}0&0\\0&0\end{pmatrix}$$
Свойства: $\operatorname{rank} = 0$, $\det = 0$ (для квадратной).
Структура

Единичная

Квадратная матрица с единицами на главной диагонали и нулями в остальных позициях.

$$a_{ii} = 1,\quad a_{ij} = 0 \ (i \neq j)$$
Пример: $$I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$$
Свойство: $AI = IA = A$ — нейтральный элемент умножения.
Структура

Диагональная

Все внедиагональные элементы — нули.

$$a_{ij} = 0 \ (i \neq j)$$
Пример: $$\operatorname{diag}(2, 5, 7) = \begin{pmatrix}2&0&0\\0&5&0\\0&0&7\end{pmatrix}$$
Свойство: $\det = \prod a_{ii}$ — произведение диагональных элементов.
Структура

Скалярная

Диагональная матрица, у которой все диагональные элементы одинаковы: $A = \lambda I$.

$$a_{ii} = \lambda \;\forall i$$
Пример: $$3I = \begin{pmatrix}3&0\\0&3\end{pmatrix}$$
Свойство: Умножение на скаляр — частный случай матричного умножения.
Структура

Верхняя треугольная

Все элементы ниже главной диагонали — нули.

$$a_{ij} = 0 \;(i > j)$$
Пример: $$\begin{pmatrix}1&2&3\\0&4&5\\0&0&6\end{pmatrix}$$
Зачем: $\det = \prod a_{ii}$. Используется в LU-разложении.
Структура

Нижняя треугольная

Все элементы выше главной диагонали — нули.

$$a_{ij} = 0 \;(i < j)$$
Пример: $$\begin{pmatrix}1&0&0\\2&3&0\\4&5&6\end{pmatrix}$$
Зачем: Матрица $L$ в LU-разложении и разложении Холецкого.

Симметрия

Свойства относительно главной диагонали и транспонирования.

Симметрия

Симметричная

Совпадает со своей транспонированной: $A = A^T$.

$$a_{ij} = a_{ji}$$
Пример: $$\begin{pmatrix}1&2\\2&3\end{pmatrix}$$
Свойства: Собственные значения вещественны. Всегда диагонализируема ортогонально: $A = QDQ^T$.
Симметрия

Кососимметричная

Равна минус своей транспонированной: $A = -A^T$.

$$a_{ij} = -a_{ji}$$
Пример: $$\begin{pmatrix}0&1\\-1&0\end{pmatrix}$$
Свойства: Диагональ — нули. Все собственные значения чисто мнимые или нули.
Симметрия

Эрмитова

Комплексная матрица, равная своему эрмитово сопряжённому: $A = A^*$.

$$a_{ij} = \overline{a_{ji}}$$
Пример: $$\begin{pmatrix}1&i\\-i&2\end{pmatrix}$$
Свойства: Все собственные значения вещественны. Аналог симметричной для $\mathbb{C}$.
Симметрия

Ортогональная

Квадратная матрица, у которой $A^T A = I$, то есть $A^{-1} = A^T$.

$$A^T A = A A^T = I$$
Пример: $$\begin{pmatrix}0&-1\\1&0\end{pmatrix}$$ — поворот на 90°
Свойства: Столбцы — ортонормированный базис. $\det = \pm 1$.
Симметрия

Унитарная

Комплексная матрица, у которой $A^* A = I$, то есть $A^{-1} = A^*$.

$$A^* A = A A^* = I$$
Пример: $$\frac{1}{\sqrt{2}}\begin{pmatrix}1&i\\i&1\end{pmatrix}$$
Свойства: Аналог ортогональной в $\mathbb{C}$. $|\det| = 1$.

Определённость

Знак квадратичной формы $x^T A x$ для симметричных матриц.

Определённость

Положительно определённая

Симметричная матрица, для которой квадратичная форма строго положительна при ненулевом $x$.

$$x^T A x > 0 \;\forall x \neq 0$$
Эквивалентно: Все собственные значения $> 0$; все главные миноры $> 0$ (критерий Сильвестра).
Применение: Оптимизация (минимум), разложение Холецкого, теория упругости.
Определённость

Отрицательно определённая

Симметричная матрица, для которой квадратичная форма строго отрицательна при ненулевом $x$.

$$x^T A x < 0 \;\forall x \neq 0$$
Эквивалентно: Все собственные значения $< 0$; знаки главных миноров чередуются, начиная с минуса.
Применение: Поиск точки максимума в оптимизации.
Определённость

Знаконеопределённая

Симметричная матрица, для которой $x^T A x$ принимает как положительные, так и отрицательные значения.

$$\exists x: x^T A x > 0,\quad \exists y: y^T A y < 0$$
Эквивалентно: Собственные значения разных знаков.
Применение: Седловая точка в оптимизации.

Особые виды

Матрицы со специальными алгебраическими свойствами.

Особое

Идемпотентная

Матрица, равная своему квадрату: $A^2 = A$.

$$A \cdot A = A$$
Пример: $$\begin{pmatrix}1&0\\0&0\end{pmatrix}$$ — проектор на ось $x$
Свойства: Собственные значения 0 или 1. Используется как матрица проектирования.
Особое

Инволютивная

Матрица, квадрат которой равен единичной: $A^2 = I$.

$$A \cdot A = I$$
Пример: $$\begin{pmatrix}0&1\\1&0\end{pmatrix}$$ — отражение
Свойства: $A = A^{-1}$. Собственные значения $\pm 1$.
Особое

Нильпотентная

Матрица, некоторая степень которой равна нулю: $A^k = 0$.

$$\exists k \geq 1: A^k = 0$$
Пример: $$\begin{pmatrix}0&1\\0&0\end{pmatrix}$$ — $A^2 = 0$
Свойства: Все собственные значения нули. $\det = 0$.
Особое

Перестановочная

Матрица перестановок — получается из единичной перестановкой строк.

$$P = \text{перестановка строк } I$$
Пример: $$\begin{pmatrix}0&1\\1&0\end{pmatrix}$$
Свойства: $P^T = P^{-1}$. $\det = \pm 1$. Используется в LUP-разложении.

Числовые характеристики

Определитель, ранг, след, спектр.

Число

Определитель

Скалярная характеристика квадратной матрицы, равная коэффициенту изменения объёма.

$$\det(A) = |A|$$
Свойства: $\det(AB) = \det(A)\det(B)$; $\det(A^{-1}) = 1/\det(A)$; $\det(A^T) = \det(A)$.
Применение: Проверка обратимости, правило Крамера, замена переменных.
Число

Ранг

Максимальное число линейно независимых строк (или столбцов).

$$\operatorname{rank}(A) \le \min(m, n)$$
Как вычислить: Число ненулевых строк в ступенчатой форме.
Применение: Критерий Кронекера-Капелли, размерность образа и ядра.
Число

След

Сумма элементов главной диагонали.

$$\operatorname{tr}(A) = \sum_{i} a_{ii}$$
Свойства: $\operatorname{tr}(AB) = \operatorname{tr}(BA)$. Равен сумме собственных значений.
Применение: Норма Фробениуса: $\|A\|^2 = \operatorname{tr}(A^*A)$.
Число

Собственные значения

Числа $\lambda$, при которых $A v = \lambda v$ имеет ненулевое решение.

$$\det(A - \lambda I) = 0$$
Инварианты: $\sum \lambda_i = \operatorname{tr}(A)$; $\prod \lambda_i = \det(A)$.
Применение: Устойчивость систем, PCA, квантовая механика.

Вырожденность и обратимость

Существование обратной матрицы и связанные свойства.

Вырожденность

Невырожденная (обратимая)

Квадратная матрица, у которой существует обратная: $A^{-1}$ такая, что $A A^{-1} = A^{-1} A = I$.

$$\det(A) \neq 0$$
Эквивалентно: $\operatorname{rank}(A) = n$; столбцы линейно независимы; СЛАУ $Ax=b$ имеет единственное решение.
Формула: $A^{-1} = \dfrac{1}{\det A}\operatorname{adj}(A)$.
Вырожденность

Вырожденная (сингулярная)

Квадратная матрица, у которой обратной не существует.

$$\det(A) = 0$$
Эквивалентно: $\operatorname{rank}(A) < n$; строки или столбцы линейно зависимы; система $Ax=b$ либо несовместна, либо имеет бесконечно много решений.
Геометрически: Преобразование сжимает пространство в подпространство меньшей размерности.
